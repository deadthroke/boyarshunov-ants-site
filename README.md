# 🐜 МУРАВЬИ-МСТИТЕЛИ против ДОКТОРА ДУМА (Земля-616-Миллиметров)

Красочный, интерактивный одностраничный супергеройский сайт-комикс о противостоянии защитников Великого Муравейника против тирании правителя Латверийского Пня — Доктора Муравья Дума!

---

## 🌟 Основные особенности сайта

1. **Главный экран (Hero Section)**:
   - Эпическая широкоформатная сцена битвы у старого дуба.
   - Динамический фон на HTML5 Canvas (падающие сосновые хвоинки, искры сахара и биоплазма).
   - Живой счетчик метрик колонии (1 500 000+ рабочих муравьев).
   - Кнопка воспроизведения героического синтез-гимна.

2. **Хроника Сахарной Войны (Комикс-пролог)**:
   - 4 интерактивные панели в комикс-стиле со звукоподражательными репликами («БАМХ!», «КЛАЦ!», «ДЗЫНЬ!»).
   - Предыстория похищения священного кубика рафинада.

3. **Секретные материалы разведки (Досье бойцов)**:
   - Интерактивные карточки с фильтрацией по сторонам конфликта (**Муравьи-Мстители** / **Легион Дума**).
   - 8 детально проработанных персонажей с уникальными векторными иллюстрациями:
     - 🛡️ **Капитан Муравей (Стив Роджерс-Мураш)** со щитом из крышки колы.
     - ⚡ **Железный Муравей (Энтони Стерк)** с нектарным дуговым реактором.
     - 👑 **Доктор Муравей Дум (Виктор фон Мурав)** с титановой маской и плащом из мха.
     - 🔨 **Тор-Муравей** со священным часовым винтиком Мьёльниром.
     - 🧪 **Муравьиный Халк** в шортах из лепестка фиалки.
     - 🕷️ **Черная Муравьиха** с электро-жалами.
     - 🏹 **Соколиный Ус** со стрелами из шипов роз.
     - 🤖 **Дум-Бот «Тля-Уничтожитель» (DM-07)**.
   - Модальное окно с расширенной биографией, суперсилами, экипировкой и кнопкой воспроизведения боевого клича.

4. **Интерактивная мини-игра «Битва за Сахарный Трон»**:
   - Полноценная 60 FPS аркада прямо в браузере.
   - Выбор бойца: скорострельный Железный Муравей или рикошетящий щит Капитана Муравья.
   - Волны кибер-тлей и летающих ос.
   - Битва с боссом — Доктором Муравьем Думом (изумрудные лучи, телепортация и шкала HP).
   - Сбор кристаллов сахара для очков и восстановления здоровья.
   - Управление на клавиатуре (`A`/`D` или стрелки, `Пробел` — выстрел) и тач-кнопки для мобильных устройств.
   - Сохранение рекорда в `localStorage`.

5. **Сканер угрозы Дума (Интерактивный калькулятор)**:
   - Расчет вероятности нападения на ваш дачный газон или подоконник.
   - Динамический радиальный индикатор угрозы.
   - Кнопка копирования секретного отчета разведки в буфер обмена.

6. **Режим Дума (Doom Takeover Mode)**:
   - Пасхалка: кнопка «РЕЖИМ ДУМА» переводит сайт в зеленый авторитарный латверийский стиль с ЭЛТ-сканлайнами и злодейским смехом.

7. **Звуковой движок Web Audio API**:
   - Все звуки (выстрелы репульсоров, звон крышки-щита, взрывы, сбор сахара, злодейский смех и гимн) синтезируются алгоритмически прямо в браузере — никаких внешних тяжелых mp3 файлов и 100% надежная работа оффлайн.

## 📁 Структура файлов проекта

- [`index.html`](file:///y:/MURAVIECOM/index.html) — главная страница сайта со всеми секциями.
- [`error.html`](file:///y:/MURAVIECOM/error.html) — стилизованная страница ошибки 404 («Обвал туннеля Муравейника») с интерактивной мини-механикой раскопок завала.
- [`style.css`](file:///y:/MURAVIECOM/style.css) — комикс-стилизация, адаптивная верстка, анимации, тема Дума.
- [`script.js`](file:///y:/MURAVIECOM/script.js) — синтезатор звуков Web Audio, игра, калькулятор, частицы.
- [`assets/`](file:///y:/MURAVIECOM/assets/) — векторные SVG-иллюстрации героев и артефактов.

## 🚀 Как запустить

### Способ 1: Без установки (мгновенно)
Просто откройте файл `index.html` в любом браузере (Google Chrome, Edge, Firefox, Safari и др.) двойным щелчком мыши.

### Способ 2: Через локальный сервер Node.js
```bash
npm start
# или
npx serve .
```
Затем откройте в браузере адрес, указанный в консоли (обычно `http://localhost:3000`).
